## 📱 About Pocket Log

Pocket Log is a beautiful, modern, and feature-rich personal expense tracker built with **Jetpack Compose**.

Designed to help you manage your personal finances with ease, Pocket Log combines a clean Material 3 interface, powerful analytics, debt and loan management, budgeting, offline-first storage, and professional reporting — all while keeping your financial data private.

Whether you want to track daily expenses, manage multiple wallets, monitor budgets, or understand your spending habits, Pocket Log gives you the tools to stay in control of your money.

## 🏗️ Tech Stack

| Technology | Implementation |
|---|---|
| Language | Kotlin |
| UI Framework | Jetpack Compose (Material 3) |
| Architecture | MVI + Clean Architecture |
| Dependency Injection | Koin |
| Database | Room |
| Navigation | Type-safe Compose Navigation |
| Background Tasks | WorkManager |
| Storage | DataStore |
