# 💰 Pocket Log

A beautiful, modern, and feature-rich expense tracker built with **Jetpack Compose**, designed to help you manage your personal finances with ease. Pocket Log combines a clean Material 3 interface, powerful analytics, debt & loan management, budgeting, offline-first storage, and professional reporting—all while keeping your data completely private.

# 🏗 Tech Stack

* **Language:** Kotlin
* **UI:** Jetpack Compose (Material 3)
* **Architecture:** MVI + Clean Architecture
* **Dependency Injection:** Koin
* **Database:** Room
* **Navigation:** Type-safe Compose Navigation
* **Background Tasks:** WorkManager
* **Storage:** DataStore
* **Serialization:** Kotlinx Serialization
* **Charts:** Custom Compose Canvas
* **PDF Generation:** Android PdfDocument
* **Icons:** Vecto Icons
